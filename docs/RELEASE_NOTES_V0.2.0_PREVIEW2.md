# OpenDesk Free v0.2.0 Preview 2

Supersedes Preview 1. English-first UI with selectable Vietnamese; language preference saved in a localhost browser cookie across random ports. New PDF operations: merge, split into a ZIP with one PDF per page, rotate 90 degrees clockwise. Uses pdfcpu v0.16.3 under Apache-2.0. Automated bilingual and real PDF tests run on Windows GitHub Actions. OCR remains NOT IMPLEMENTED. Unsigned preview; end-user Windows installation and removal still require manual acceptance testing.
