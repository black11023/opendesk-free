## Selection criteria

Offline/self-hosted capability, no mandatory subscription for core use, community maintenance, security and accessible installation, international use and an identifiable upstream license. **The list is curated, not exhaustive and not an endorsement/security certification.** Free of charge does not necessarily mean an OSI-approved open source license or entirely free hosted services.

## Read before licensing an integration

Upstream licenses are not interchangeable. GPL/AGPL and MPL have redistribution/derivative-work requirements; some community projects include separate enterprise-licensed code and trademarks. Review the exact upstream release and all transitive dependencies before using, linking or redistributing code. Do not copy names, logos or executables into installers without license/trademark checks.
