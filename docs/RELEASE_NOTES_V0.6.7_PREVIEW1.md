# OpenDesk Free V0.6.7 Preview 1 — Focused FormGuard

Removed generic PDF editing/ZIP/CSV tools and the 44-project directory from the visible workbench. Legacy backend operations remain temporarily for compatibility. New built-in **FormGuard preflight** scans DOCX/XLSX/PPTX structure without altering source files; exports a CSV including original SHA-256, OOXML parts, text/formula/numeric/merge counts and READY/REVIEW/BLOCKED findings. Optional local image/PDF OCR remain in the UI as preparation for future translation.

**Not yet a translator:** multilingual models, Word/Excel/PDF translated outputs and layout preservation remain under development; no model or cloud service is bundled. Executables unsigned Preview. Windows tests, real Office/OCR, Chromium and ClamAV gate required before release.
