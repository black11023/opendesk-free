# Contributing to OpenDesk Free

Thank you for helping make useful software accessible to everyone.

1. Create a GitHub Issue describing the problem, with small nonsensitive reproduction files.
2. Open a feature branch, add Go unit tests or UI test instructions as appropriate, and ensure `go test ./...` passes.
3. Open a pull request with a clear problem statement, behavior change, and screenshots only if they contain no personal or private data.
4. Keep all default functionality free, local-first and transparent. Do not introduce telemetry or mandatory paid services.
5. Do not submit personal documents, passwords, tokens, copyrighted fonts or other third-party materials without permission.

Security vulnerabilities: do not post exploitation details publicly before a safe reporting channel is configured. Contact repository maintainers privately.
